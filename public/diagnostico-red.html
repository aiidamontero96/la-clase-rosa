Qué hacer con el resultado
  • Repite la misma prueba en la PDI con Andared y, si puedes, con la conexión móvil. Usa el mismo navegador y el mismo enlace.
  • Un archivo que responde con una página HTML en lugar de JavaScript o CSS puede indicar una redirección o una página de filtrado; no identifica por sí solo el responsable.
  • «Sin respuesta» puede deberse a red, certificado, DNS, filtrado o servidor. El navegador no permite distinguirlos todos desde JavaScript.
  • Para CAUCE, adjunta el informe y la captura del error. Solicita revisar el acceso HTTPS a www.laclaserosa.es y laclaserosa.es, la clasificación del dominio y, si existe inspección HTTPS, su cadena de confianza.
  • No instales certificados descargados de fuentes desconocidas ni desactives la comprobación de certificados. La coordinación TDE o CAUCE debe facilitar cualquier configuración oficial necesaria.
