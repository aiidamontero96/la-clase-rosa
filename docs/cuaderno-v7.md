# Cuaderno v7

Aplicar sobre el cuaderno v6 (contornos y resumen consecutivo).

- Portadas con medidas iguales e índice interior en doce casillas iguales.
- Dos palabras del proyecto por semana, con imagen de referencia y explicación oral.
- Ruta del trimestre como primera pestaña y selección inicial.
- Presentación final de veinte diapositivas con las dos páginas de resumen de cada semana. Visor web con navegación y descarga PPTX. Sin descargas semanales.
- Menú móvil con fondo blanco opaco.

Validación: sintaxis JS, comprobación de las 120 páginas, recursos locales, compilación y PPTX de veinte diapositivas exportado y renderizado. La presentación conserva las láminas como imágenes, no como texto editable. No se ha comprobado este cambio en un dispositivo físico.
